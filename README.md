# Calculadora para iPhone

Calculadora web instalable, diseñada para iPhone 15 a partir de las referencias proporcionadas.

- Operaciones básicas con prioridad de multiplicación y división.
- Porcentajes, cambio de signo, borrado y coma decimal.
- Separación de miles con puntos.
- Reducción de tamaño con 10 y 11 dígitos; difuminado izquierdo desde 12.
- Expresión sobre el resultado al resolver la operación.
- Iconos superiores decorativos.
- Manifest y service worker para instalación y uso sin conexión tras la primera carga.

## Uso

Publica estos archivos en un alojamiento estático HTTPS. Abre la URL en Safari y selecciona Compartir > Añadir a pantalla de inicio.

## Validación

Se han superado ocho comprobaciones de aritmética e interacción. Queda pendiente verificar visualmente en Safari del iPhone 15.

El proyecto no necesita dependencias ni compilación.
